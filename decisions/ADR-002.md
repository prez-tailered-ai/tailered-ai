# ADR-002: Use a typed vendor-neutral orchestration core

## Context

v1 must execute without welding company state or routing policy to one model provider. It also needs deterministic local verification of every terminal path.

## Decision

Implement the runtime in strict TypeScript on Node.js 24. Model work crosses a metered JSON process protocol. The deterministic todo agent uses the same orchestration interface for the executable gating demonstration.

## Alternatives rejected

- Put provider-specific API calls throughout the ship loop.
- Create a separate demo-only orchestration path.
- Store run state in a dashboard service.

## Consequences

- Provider upgrades remain isolated behind one process boundary and the model registry.
- CI can prove reserve/settle, routing, gates, terminal ledgers, supersession, and dashboard rendering without credentials.
- A production agent must supply hard cost and token ceilings before every invocation.
