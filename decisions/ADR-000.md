# ADR-000: Tailered AI charter

## Context

Model intelligence is rented and broadly available. Durable advantage comes from proprietary context, executable ground truth, labeled judgment, closed feedback loops, and legible decision history.

## Decision

Build Tailered AI as a company factory whose unit of output is a founder-owned Git repository containing product code and the operating company around it.

## Alternatives rejected

- Build another application generator that outputs product code only.
- Hold authoritative company state in a Tailered database.

## Consequences

- Plain repository files are the public contract and the sole company state.
- Every enduring feature must strengthen capture, replayability, governance, or credit assignment.
